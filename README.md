# Passenger Queue Dynamics and Waiting-Time Simulation for Selected M66 Bus Stops

This repository contains the data preparation, dataset analysis, AI demand-model evaluation, GTFS schedule processing, discrete-event simulation, scenario experiments, and visualization code for the MODESIM project.

The project simulates passenger queue dynamics and waiting-time outcomes at five consecutive eastbound M66 bus stops in Manhattan during weekday morning and evening periods. It uses 2025 MTA Bus Stop Level Ridership data for passenger-demand analysis and the current Manhattan MTA GTFS schedule for simulated bus-arrival events.
